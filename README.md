# Enhancing Thyroid Disease Diagnosis with Machine Learning and Counterfactual Explainable AI

## 📌 Overview
This project focuses on enhancing thyroid disease diagnosis using machine learning algorithms and explainable artificial intelligence techniques. The system predicts thyroid conditions such as Normal, Hypothyroid, and Hyperthyroid using clinical and laboratory features.

The project also integrates SHAP and Counterfactual Explainable AI to improve model transparency and interpretability for healthcare decision support.

---

## 🎯 Objectives
- Predict thyroid disease accurately using machine learning
- Compare multiple classification algorithms
- Identify important clinical features
- Improve model interpretability using Explainable AI
- Generate counterfactual explanations for predictions

## 🧠 Explainable AI
### SHAP Explainability

### Counterfactual Explainable AI
Counterfactual explanations generate minimal feature changes required to alter model predictions, improving transparency and clinical understanding.

## 📌 Results
Random Forest and CatBoost achieved the highest prediction performance with excellent classification accuracy and ROC-AUC scores.

The selected top clinical features significantly improved prediction performance while reducing model complexity.
